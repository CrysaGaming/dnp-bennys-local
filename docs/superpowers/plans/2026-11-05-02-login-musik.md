# Benny's Portal – Plan 02: GTA-Login und Musik (Phase 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Login-Seite im GTA-V/VI-Stil mit Intro, animierten Ebenen, Status-Bannern und Hintergrundmusik. Dazu die Musik im Dashboard, pro User an- und abschaltbar.

**Architecture:** Ein `MusicProvider` im Root-Layout hält das einzige `<audio>`-Element. Deshalb läuft die Musik über Seitenwechsel hinweg. Die Login-Szene ist ein kleiner Zustandsautomat (`intro → scene → success`), der die Animationskomponenten steuert. Die Login-Logik selbst bleibt das `LoginForm` aus Plan 01.

**Tech Stack:** motion 14.9.1, sharp 0.35.5 (nur Skript), next/image.

**Spec:** `docs/superpowers/specs/2026-11-05-bennys-portal-design.md` (Abschnitte 6, 12.2)

## Global Constraints

Gelten wie in `2026-11-05-00-uebersicht.md`. Zusätzlich für diesen Plan:
- Musik startet nie ohne Nutzeraktion. Ein abgelehntes `play()` ist kein Fehler, sondern der Zustand `blocked`.
- Die Musikquelle kommt aus `NEXT_PUBLIC_MUSIC_SRC` (Standard `/audio/strassen-im-blut.mp3`). Fehlt die Datei, wird der Player ausgeblendet (`available: false`).
- Animationen nutzen nur `transform` und `opacity`.

## Review Focus

Kein Punkt aus der Übersicht liegt in diesem Plan. Zusätzlich abgedeckt: Der Browser blockiert Autoplay nach dem Neuladen im Dashboard. Erwartung: Der Button zeigt „pausiert“, die Musik startet beim ersten Klick (Task 3.4).
